ClimaExplore User Guide

Welcome to ClimaExplore — an open-source scientific desktop and web platform built for climate data processing, deep learning predictions, wavelet analysis, and geospatial visualization.

Features Summary

  • Data Input: Import CSV/NetCDF datasets, view raw tabular data, and compute summary metrics.
  • CNN+GRU Model: Train deep learning models with live loss/RMSE metrics curves.
  • Wavelet Analysis: Continuous Wavelet Transform (CWT) scalogram power spectrum plotting.
  • Map Plots: Interactive climate grid field rendering with time slider navigation.
